## Три исходные оценки

| Работа / ID | Роль | Единица | O | M | P | Источник и допущение | Риски в O/M/P |
| --- | --- | --- | --- | --- | --- | --- | --- |
| | | | | | | | |

Для одной работы и единицы: 0 ≤ O ≤ M ≤ P, только конечные числа.
Пустое поле означает отсутствие оценки, а не ноль.

PERT = (O + 4 × M + P) / 6; разброс σ = (P − O) / 6.
Сначала считайте без округления, для отображения укажите точность.
Без данных о распределении интервал ±2σ не означает гарантии 95%.
Инженер заполняет O/M/P в чел·ч. В последней колонке перечислите через запятую
ID рисков, последствия которых уже вошли в оценку. Чиф пересчитает сводку после сохранения.

## Ёмкость, календарь и ресурсы

- Люди по ролям, рабочие дни, часы в день, доля участия и фокус-фактор: нет данных.
- Ёмкость = сумма по людям (дни × часы × доля участия × фокус-фактор).
- Зависимости, ожидания и дата старта: не определены.
- Агент: слоты, минуты занятия, входные / выходные токены и повторы — нет данных.
- Стоимость: ставки / тарифы, валюта, дата и источник — нет данных.
- API = (входные токены × тариф входа + выходные × тариф выхода) / 1 000 000
  для тарифов за миллион токенов.
- Инфраструктура и хранение: необходимость не определена.

Труд человека, время агента, календарный срок и деньги учитывайте отдельно.
Длительность открытой задачи не равна человеко-часам.
Правило трёх частей помогает найти пропущенные работы; одинаковые доли допустимы
как явно записанное раннее допущение. Итог с неизвестными строками — частичный.
